# ⌨️ NEXORA — Product Detail Page (E-commerce UI)

Modern high-end e-commerce product page built for a fictional premium tech brand.  
Designed to simulate a real-world product detail experience with interactive UI components and conversion-focused structure.

---

## 🚀 Overview

Nexora Product Page is a fully interactive product detail UI inspired by modern e-commerce platforms such as Apple, Logitech, and Razer.

The project focuses on realistic product presentation, structured information flow, and user-friendly shopping interactions.

---

## 🎯 Key Features

- 🖼️ Product image gallery with thumbnail switching  
- 🛒 Functional add-to-cart system  
- 📦 Cart dropdown with dynamic item tracking  
- 💰 Price display with clean product hierarchy  
- 📑 Expandable product information sections (accordion UI)  
- 🚚 Shipping information module  
- 🛡️ Warranty & support section  
- 🔁 “You may also like” product recommendations  
- 🌍 Multi-language system (Estonian / English via `data-i18n`)  
- 🎨 Clean premium tech aesthetic UI  

---

## 🧱 Tech Stack

- HTML5  
- CSS3  
- Vanilla JavaScript  
- Custom cart logic (no frameworks)  
- Custom i18n translation system  

---

## 🛍️ Project Concept

This project simulates a real-world e-commerce product detail page for a premium gaming hardware brand.

Inspired by:
- Apple product pages  
- Logitech G series  
- Razer product UI systems  

The goal was to replicate a realistic shopping experience with:
- structured product storytelling  
- interactive UI components  
- conversion-focused layout  
- modular information sections  

---

## 🧠 What I Learned

- Managing UI state (cart, dropdowns, sections)

## 🌍 Language Support

The project uses a lightweight translation system based on `data-i18n` attributes.

Supported languages:
- Estonian (default)
- English
